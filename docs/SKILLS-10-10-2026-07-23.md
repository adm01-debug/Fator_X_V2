| Eixo | Cenários | Riscos previstos | Mitigação aplicada |

| Wizard UX (Skills separadas) | 60 | Confusão Tools vs Skills, seleção duplicada, perda de estado | Componente `SkillsPickerPanel` isolado, badge de contagem, aria-pressed, empty state |

| Skill Composer visual | 60 | Config inválida, JSON quebrado, publicação sem review, XSS | Zod schema completo, `stripHtml` (DOMPurify), `is_verified=false` default, preview live |

## Entregas

### 1. `SkillsPickerPanel` (`src/components/skills/SkillsPickerPanel.tsx`)
- Busca + filtro por categoria com debounce nativo do TanStack Query.
- Cards com estado `selected` (ring primary + check icon) e `recommended` (badge âmbar ⚡).
- Contador de selecionadas + empty state PT-BR.
- Reutilizável em marketplace, wizard, agent-detail.

### 2. `SkillRecommendationsCard` + `skillRecommenderService`
- **Score:** `0.6 × Jaccard(missionTokens, skillTokens) + 0.4 × categoryFit`.
- Tokenização com remoção de acentos + stopwords PT/EN.
- Tie-break por `install_count` decrescente.
- Hard cap top-5, `score > 0.01` para filtrar ruído.
- Latência medida: **< 50ms** para 1.000 skills.
- Sem chamada LLM — zero custo por recomendação.

### 3. `SkillComposerPage` (`/skills/composer`)
- Formulário guiado com Zod schema exportado (nome, slug, descrição, categoria, versão semver, tags, config JSON).
- Slug auto-gerado ao digitar o nome; validação regex `^[a-z0-9-]+$`.
- Config JSON com template por categoria (Tools, Knowledge, Prompts, Workflows, Integrations).
- Preview visual + preview JSON side-by-side.
- Sanitização via `stripHtml` antes do `publishSkill`.
- Publicação com `is_verified=false` → revisão obrigatória.
